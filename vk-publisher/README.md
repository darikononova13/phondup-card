# PHONDÜP — публикации во ВКонтакте

Это отдельный модуль в уже подключённом репозитории электронной визитки. Файлы визитки в папке public/ не менялись. Группа: https://vk.ru/phondup.

## Безопасное подключение ключа (один раз)

1. Откройте https://github.com/darikononova13/phondup-card/settings/secrets/actions
2. Нажмите **New repository secret**.
3. В поле **Name** введите `VK_ACCESS_TOKEN`.
4. В поле **Secret** вставьте созданный в настройках VK API токен и сохраните кнопкой **Add secret**.
5. Откройте вкладку **Actions** в репозитории, выберите **PHONDUP VK — publish approved posts**, нажмите **Run workflow**. Это только проверка получения ID сообщества — публикация не выполняется.

⚠️ Никогда не помещайте ключ в чат, GitHub-файлы, скриншоты или сообщения клиентам. Если ключ случайно раскрыт, отзовите его и создайте новый. Ключ сообщества может оказаться недостаточным для wall.post; в таком случае понадобится другой тип авторизации, а не передача дополнительных секретов в чат.

## Как позже публиковать

После вашего подтверждения окончательного текста создаётся **новый** файл в `vk-publisher/outbox/` с уникальным именем, например `2026-10-27-phondup-display.json`:

```json
{
  "approved": true,
  "message": "Пример текста публикации. Не отправлять без подтверждения.",
  "attachments": []
}
```

Только **новый** файл в папке outbox, добавленный в ветку main, запускает публикацию. `approved` должно быть `true`. `attachments` — массив уже загруженных в VK идентификаторов `photo-12345_67890` или `video-12345_67890`.

Готовые фотографии и видео пока нужно загружать в VK отдельно: автоматическая загрузка новых файлов ещё не подключена и может требовать другого типа токена. Для текстов и уже загруженных вложений предусмотрен маршрут публикации.

Результат и ссылку на опубликованный пост можно увидеть во вкладке **Actions** в журнале соответствующего запуска. Секрет в журнал не выводится.

## Ограничения

- Проверка ключа не доказывает наличия прав на публикацию. Первую публикацию делайте только после проверки разрешений и утверждения текста.
- В этом модуле нет планировщика публикаций или чтения комментариев; это следующие этапы.
- GitHub Actions не являются прямым интеграционным коннектором к интерфейсу ChatGPT. После вашего одобрения можно создавать файл в GitHub с помощью подключённого инструмента.
- Для экономии и защиты данных не добавляйте клиентские персональные сведения в публичный репозиторий.
